# Changelog

Notable changes to Bones are documented here. The project follows Semantic
Versioning.

## [1.0.0] - 2026-08-20

### Added

- Stable workflows for transects, occurrences, instances, images, reference
  data, audit history, and analytical reports.
- Responsive Django interface with reusable list, detail, filtering, and
  master-detail page patterns.
- SQL Server-backed production operation and deterministic SQLite test support.
- Versioned GHCR release images with immutable tags, SBOMs, and provenance
  attestations.

### Security

- Python 3.14 and Django 6.1 runtime baseline.
- Protected pull requests with Django, container, CodeQL, and dependency-review
  checks.
- Secret scanning, push protection, Dependabot, private vulnerability
  reporting, SHA-pinned Actions, and OpenSSF Scorecard monitoring.
