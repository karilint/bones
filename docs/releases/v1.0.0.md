# Bones v1.0.0

Bones v1.0.0 is the first stable release of the application.

## Highlights

- Manage transects, occurrences, instances, images, reference data, and survey
  workflows through a responsive Django interface.
- Filter and review linked image records and navigate directly to their related
  entities.
- Produce analytical reports while retaining auditable record history.
- Run on Python 3.14 and Django 6.1 with Microsoft SQL Server in production.

## Supply-chain integrity

The release container is published to `ghcr.io/karilint/bones` with semantic
version tags, an immutable commit-SHA tag, an SBOM, and signed GitHub provenance
attestations. Python dependencies and container base images are hash- or
digest-pinned.

## Upgrade notes

This is the initial stable release, so there is no prior stable-version upgrade
path. Existing deployments should back up their configuration and database,
then deploy the `1.0.0` image rather than a mutable development tag.
